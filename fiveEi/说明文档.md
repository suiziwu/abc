2026-10-27 做过一次目录整理，所有目录与文件已按用途分类并改为中文命名，脚本内部的路径常量同步改好，可直接运行。

## 五、人才培养工作流（10-人才培养工作流/）

给「人才培养方案」页面供数的智能工作流：输入专业群 + 材料（官方报告 / 新闻 / 招聘数据 / 岗位样本），调用 DeepSeek 产出
`KPI`、`岗位需求表`、`技能热度表`、`预警表`、`培养建议表`、`数据缺口表` 与图表数据，**函数直接返回 dict，不生成中间文件**。

```powershell
cd 10-人才培养工作流
$env:DEEPSEEK_API_KEY = "sk-xxxx"     # 或用 config.json 的 api.api_key
python -m talent_workflow --check     # 测接口
python 运行示例.py                     # 命令行打印数据表
```

- 模型、接口地址、提示词、并发、校验阈值都在 `config.json`，改提示词不需要动代码。
- 每条预警/建议都带来源编号和原文证据；流水线会自动校验（来源是否存在、证据是否出自原文、数字是否能对上），不合格自动让模型修一轮。
- **预生成看板**：`python 生成页面数据.py` 把结果写成 `网页看板/数据.js`，双击 `网页看板/index.html` 即可打开（不调接口、不依赖服务器）；重新生成会自动给脚本打版本号，避免浏览器缓存旧数据。
- 预生成版已复制到 `D:\123123\smart-manufacturing-talent-dashboard-预生成版\`，原看板目录未改动。
- 详细输入输出格式、页面字段映射见 `10-人才培养工作流/README.md`。
